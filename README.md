# Chrome 流量统计大师 (v2.1)

这是一个用于 Google Chrome 浏览器的网页流量统计插件（v2.1 版本），完美集成了平滑曲线图、域名/网址流量精确排行以及无缝数据继承升级机制。

## v2.1 核心功能与亮点

1. **多维度平滑曲线图**：支持按 **日**、**月**、**年** 自动归档并展示流量消耗的动态平滑曲线趋势图（Line Chart）。
2. **域名/网址流量排行**：支持按访问域名分类统计各网站流量，并按流量高低实时倒序排序。
3. **无缝数据继承升级**：支持覆盖更新升级，自动保留和继承之前版本中保存在本地存储的所有历史流量数据，绝不丢失。
4. **会话重启隔离**：每次重新打开浏览器时自动开启全新的“本次会话流量记录”，同时妥善保存历史日志。
5. **灵活清理机制**：支持按需清理（仅清空本次会话、今日记录、域名统计或全盘清空）。
6. **完全符合 Manifest V3 CSP 规范**：无远程 CDN 脚本阻塞风险，安全稳定。

---

## 快速安装与升级（继承旧数据）

1. 将本压缩包解压到本地文件夹。
2. 打开 Google Chrome 浏览器，在地址栏输入 `chrome://extensions/` 并回车。
3. 开启右上角 **“开发者模式”**。
4. 点击 **“加载已解压的扩展程序”** 选择该解压目录（若为旧版升级，直接点击插件卡片上的 **“重新加载”** 按钮即可平滑继承旧数据）。
