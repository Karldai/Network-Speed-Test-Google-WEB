# Chrome 流量统计插件 (Chrome Traffic Monitor)

这是一个用于 Google Chrome 浏览器的网页流量统计插件，能够自动记录并统计你浏览网页时消耗的网络流量。

## 核心功能

1. **自动后台统计**：静默监听并累计所有的网络请求流量。
2. **多维度历史平滑曲线图**：支持按 **日**、**月**、**年** 自动归档并展示流量消耗的动态曲线趋势图。
3. **会话重启逻辑**：每次重新打开浏览器时自动开启全新的“本次会话流量记录”，同时妥善保存之前的历史日志。
4. **灵活清理**：支持按需清理（仅清空本次会话、仅清空今日记录、或清空所有历史数据）。
5. **完全符合 Manifest V3 CSP 规范**：已完全移除远程 CDN 依赖，所有脚本与样式本地化，防拦截、更稳定安全。

---

## 快速安装与使用

1. 将本仓库克隆或下载解压到本地。
2. 打开 Google Chrome 浏览器，在地址栏输入 `chrome://extensions/` 并回车。
3. 在右上角开启 **“开发者模式” (Developer mode)**。
4. 点击左上角的 **“加载已解压的扩展程序” (Load unpacked)**。
5. 选择本仓库所在的文件夹即可完成安装。
