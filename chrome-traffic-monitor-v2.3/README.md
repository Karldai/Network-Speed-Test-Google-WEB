# Chrome 流量统计大师 (v2.3)

这是一个用于 Google Chrome 浏览器的网页流量统计插件（v2.3 版本），新增了**上行（上传）与下行（下载）流量独立分类统计**，集成了平滑曲线图、双栏域名流量排行以及无缝数据继承升级机制。

## v2.3 核心功能与亮点

1. **上下行流量独立分类（新增）**：
   - 在顶部流量总览卡片中，单独设立了 **↑ 今日上行（上传）** 与 **↓ 今日下行（下载）** 两列独立展示区，并附带当前会话的上行/下行实时数据。
   - 后台自动区分监听请求体（Upload）与响应头（Download）字节数，精确统计双向流量。
2. **双栏域名流量排行**：域名排行列表中同时呈现 **“本次会话流量”** 和 **“历史总计流量”** 两栏对比数据。
3. **多维度平滑曲线图**：支持按 **日**、**月**、**年** 展示流量消耗的动态平滑曲线趋势图（Line Chart）。
4. **无缝数据继承升级**：覆盖更新升级时，自动保留并继承之前版本保存在本地存储的所有历史流量数据。
5. **完全符合 Manifest V3 CSP 规范**：内置本地 `chart.js`（v3.9.1），无远程 CDN 依赖，安全稳定。

---

## 快速安装与升级（继承旧数据）

1. 将本压缩包解压到本地文件夹。
2. 打开 Google Chrome 浏览器，在地址栏输入 `chrome://extensions/` 并回车。
3. 开启右上角 **“开发者模式”**。
4. 点击 **“加载已解压的扩展程序”** 选择该解压目录（若为旧版升级，覆盖原目录文件后直接点击插件卡片上的 **“重新加载”** 按钮即可平滑继承旧数据）。
